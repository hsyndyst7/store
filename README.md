## NFM STORE PROJECT
Developed a cloud-based mobile e-commerce application using Flutter
and Firebase.
Implemented real-time product listing with category filtering, seller
dashboard for product management (CRUD operations), image upload
via device gallery, and integrated WhatsApp API for order submission.
